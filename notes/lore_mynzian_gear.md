Mynzian Tools & Gear (Canon)
============================

Design Doctrine
---------------
- Smaller than expected; one-handed or blind; discardable without regret; no reflective surfaces; never implies ownership.
- If it can’t be dropped instantly, it isn’t Mynzian.

Core Gear (with Item IDs)
-------------------------
- Snapblade / Keth-Knife — `item_mynz_snapblade`
  - Palm-length ceramic-silicate edge; breaks cleanly when over-pressured; no ring, no blood groove; unbroken blades considered unlucky.
- Ghostline Cord — `item_mynz_ghostline`
  - Braided plant + fungal filament; slight elastic; absorbs vibration; for trip warnings, silent descent, tethering tools (never living beings).
- Drop-Wedges — `item_mynz_dropwedges`
  - Thumb-sized basalt wedges, flat/curved faces, carried in pairs; stabilize footing, jam doors, create false sounds when dropped.
- Ashveil Partial — `item_mynz_ashveil`
  - Shoulder wrap + hood fragment; ash-stained fibers with resin; breaks silhouette, masks heat/scent briefly, sheds fibers for misdirection.
- Blindfire Pebbles — `item_mynz_blindfire`
  - Hollow nodules with reactive dust; crush to release opaque sting cloud; never thrown, only dropped.

Specialized
-----------
- Pulse Reed — `item_mynz_pulsereed`
  - Sub-audible pulses tuned to microfauna; use once; second use in same area is lethal (predators learn pattern).
- Groundskin Pads — `item_mynz_groundskin`
  - Foot/palm wraps mimicking substrate; swapped daily; never reused across islands (cross-island scent is fatal).
- Shard Compass (False Direction Tool) — `item_mynz_shardcompass`
  - Weighted shard reacting to vibration, not magnetism; detects approaching mass/ground resonance; City misfiles as primitive navigation.

Loadouts
--------
- Scout: Snapblade, Ghostline, Groundskin Pads, Drop-Wedges.
- Courier: Ashveil, Blindfire, Shard Compass, Ghostline.
- Stationary Observer: Pulse Reed, Drop-Wedges, Groundskin Pads; no blade.

Explicitly Not Carried
----------------------
- Shields, armor, bows/slings, fire, permanent containers, identity symbols. Anything that slows reaction or implies persistence.

Philosophy
----------
“If it survives you, it remembers you.”  
“If you keep it, it keeps you.”  
“Leave less than you found.”

System Notes
------------
- Effects: faster interaction windows, reduced sound signature, increased survival during stillness. Risks: gear breaks easily, no brute-force solutions, requires attentiveness.
- Journal: entries become sparse and tool-centric; missing gear not mourned.
- Availability: gated to Thal path → Wild sub-path (context: Mynz/Lorn Scatter).
